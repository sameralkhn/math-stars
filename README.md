# نجوم الضرب 🌟

لعبة لتعليم الأطفال جدول الضرب: رحلة الجزر، سباق السيارات، فرقعة البالونات، اختبار النجوم، لعبة الذاكرة، تعلّم وردّد، ومتجر الشخصيات.

- تعمل من ملف واحد `index.html` بدون أي بناء.
- تُثبَّت على الشاشة الرئيسية كتطبيق (من قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق») وتعمل بدون إنترنت بعد أول فتح.
- حسابات (Google أو إيميل وكلمة مرور) تحفظ التقدّم في السحابة وتزامنه بين الأجهزة، عبر Firebase.

## تفعيل الحسابات (مرة واحدة)

1. افتح <https://console.firebase.google.com> وأنشئ مشروعًا جديدًا (يمكنك إيقاف Google Analytics).
2. **Authentication** ← Get started ← Sign-in method: فعّل **Email/Password** و **Google**.
3. **Firestore Database** ← Create database ← اختر موقعًا قريبًا (مثل `europe-west` أو `me-central`) ← Production mode.
   ثم في تبويب **Rules** الصق محتوى الملف `firestore.rules` واضغط Publish.
4. **Project settings** (رمز الترس) ← Your apps ← اختر رمز الويب `</>` ← سجّل التطبيق.
   انسخ قيم `firebaseConfig` إلى الملف `firebase-config.js`.
5. **Authentication ← Settings ← Authorized domains**: أضف نطاق موقعك، مثل `USERNAME.github.io`.

> قيم `firebase-config.js` ليست سرية؛ قواعد Firestore هي التي تمنع أي مستخدم من رؤية تقدّم غيره.

## النشر على GitHub Pages

Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.
بعد دقيقة يصبح الرابط: `https://USERNAME.github.io/math-stars/`

> ملاحظة: GitHub Pages للمستودعات **الخاصة** يحتاج اشتراكًا مدفوعًا (GitHub Pro). في الحساب المجاني اجعل المستودع عامًا، أو استخدم Firebase Hosting.

## طريقة حفظ التقدّم

- بدون تسجيل دخول: يُحفظ التقدّم على الجهاز فقط.
- عند أول تسجيل دخول على جهاز: يُدمج تقدّم الجهاز مع تقدّم الحساب (أعلى النجوم، كل المشتريات، أكثر الليرات).
- بعدها: كل تغيير يُرفع خلال ثانيتين، ويصل إلى الأجهزة الأخرى المفتوحة فورًا.
- عند تسجيل الخروج: يُمسح التقدّم من الجهاز (ويبقى في الحساب)، حتى لا يأخذه طفل آخر يسجّل الدخول على نفس الجهاز.
- إعدادات الصوت تبقى خاصة بكل جهاز.
